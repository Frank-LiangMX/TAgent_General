# TAgent

> 本地优先的通用 AI Agent 桌面应用，让复杂任务从对话走向真正执行。

[下载最新版](/Frank-LiangMX/TAgent_General/releases/latest) · [查看更新记录](CHANGELOG.md) · [使用文档](docs/README.md)

## 为什么选择 TAgent

- **不止回答，更能执行**：在你授权后读取项目、整理资料、修改文件、运行命令并持续完成任务。
- **一个工作台管理所有项目**：为不同项目保留独立工作区、会话、工具与上下文，随时回到上次进度。
- **本地优先，数据可控**：会话、配置和记忆默认保存在本机，不依赖云端数据库。
- **多角色协作**：把复杂目标拆成多个任务，由不同角色并行推进，并在看板中跟踪进度。
- **长期使用更懂你**：记住稳定偏好、项目事实与纠正记录，同时提供可查看、可管理的记忆界面。
- **开放且可扩展**：可连接不同模型渠道，并按工作需要添加新的能力。

## 主要功能

### 通用 Agent 工作台

通过自然语言提出目标，TAgent 会规划步骤、调用工具并反馈执行过程。你可以在关键操作前确认权限，也可以随时停止、继续或切换会话。

### 项目与多会话

每个项目拥有独立工作区。会话、草稿、附件和运行记录按项目整理，适合同时管理开发、研究、写作和日常事务。

### 看板协作与 AI Office

将大型任务拆分为清晰的待办、执行、验收和交付阶段。AI Office 会把真实任务和工作状态呈现为可视化团队空间，方便快速了解谁在做什么、哪里需要介入。

### 设计预览

在应用内预览网页和界面原型，选中具体元素后直接提出修改要求，让设计沟通更直观。

### 自动化任务

创建定时或重复任务，让资料整理、例行检查和固定流程按计划运行，并保留执行记录。

### 本地记忆

TAgent 会在你的确认和设置范围内沉淀用户偏好、项目事实、纠正记录与会话摘要，减少重复说明。

### 远程协作

可通过常用消息与办公渠道接收任务、同步进度，在离开电脑时继续掌握执行情况。

### 游戏技术美术模式

为游戏资产处理、规范检查和内容生产提供专门工作区，覆盖模型、贴图、资源审核与制作流程。

## 下载与安装

前往[最新版下载页](/Frank-LiangMX/TAgent_General/releases/latest)，选择与你的系统匹配的文件。

### Windows

- **Setup 安装版（推荐）**：运行 `TAgent.Setup.*.exe`，按提示完成安装；支持应用内自动更新。
- **Portable 免安装版**：运行 `TAgent.Portable.*.exe` 即可使用；不支持自动更新，新版本需要重新下载 Portable 文件并替换旧文件。

### macOS

- 下载 `.dmg` 后打开，将 TAgent 拖入“应用程序”。
- 也可以下载 `.zip`，解压后打开 TAgent。

首次打开时，如果系统提示应用来自网络，请在系统设置中确认允许打开。

### Linux

- `.AppImage`：添加执行权限后直接运行。
- `.deb`：适用于支持该安装格式的发行版。
- `.tar.gz`：解压后运行，适合免安装使用。

## 首次使用

1. 安装并启动 TAgent。
2. 在设置中添加一个可用的模型渠道。
3. 创建或选择项目工作区。
4. 新建会话，描述你希望完成的目标。
5. 查看执行计划，并按需要确认文件、命令或外部操作权限。

建议从范围明确的小任务开始，例如整理项目说明、检查一组文件或生成工作清单。

## 数据与更新

- 用户数据默认保存在 `~/.tagent/`。
- 开发版本使用独立目录 `~/.tagent-dev/`，不会与正式版本混用。
- 重要项目建议定期使用应用内备份功能保存个人数据。
- 安装版会自动检查更新；Portable 版本需要从下载页手动获取新版本。
